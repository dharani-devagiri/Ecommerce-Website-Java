# E-Commerce Website

A full-stack E-Commerce Website developed using:

- Java
- JSP
- Servlets
- JDBC
- MySQL
- Apache Tomcat

## Features

### User Module
- User Registration
- Login Authentication
- Product Search
- Category-wise Products
- Shopping Cart
- Order Placement
- Order Tracking

### Admin Module
- Admin Login
- Add Products
- Update Products
- Delete Products
- View Orders
- Update Order Status

## Database
MySQL database with tables:
- users
- products
- cart
- orders
- order_items

## Tools Used
- Eclipse IDE
- MySQL Workbench
- Apache Tomcat
